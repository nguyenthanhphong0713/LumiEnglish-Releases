# LumiEnglish

A desktop application designed for passive English reflex learning through smart notifications, text-to-speech support, and interactive practice modes.

## Key Features

### 1. Passive & Timed Pop-up Learning
* **Timed Pop-up Mode:** Automatically triggers reminders at custom intervals (e.g., every 15 minutes) to keep you engaged throughout the day.
* **Flexible Positioning:** Choose where pop-ups appear on your screen (e.g., Top-Center).
* **Focus & Error Handling:** Auto-focus input fields and highlight errors to reinforce correct phrasing.
* **System Tray Support:** Runs quietly in the background as a system tray app.

### 2. Sentence Management & Bulk Import
* **Add Sentences:** Easily input Vietnamese cues and English target phrases.
* **Bulk Import:** Import multiple entries via Text or CSV formats.
* **Smart Filtering:** Filter and select specific sentence categories or practice pools.

### 3. Text-to-Speech (TTS) Integration
* **Voice Customization:** Select from available voices, such as Edge TTS (e.g., US English - Jenny).
* **Speed Control:** Adjust reading speeds to match your listening comprehension level.
* **SAPI 5 / OneCore Support:** Integrates with system-level text-to-speech engines.

### 4. Progress Tracking & Statistics
* **Performance Metrics:** Track correct attempts, incorrect tries, and success ratios per sentence.
* **Recent Activity Log:** Monitor the last study timestamps.
* **Quick Management:** Audio preview, edit, clone, or delete items directly from the question bank.

## Quick Usage

1. **Add Content:** Input your translation pairs manually or via bulk import.
2. **Configure Pop-ups:** Set your preferred time interval and display position.
3. **Practice:** Let reminders prompt you naturally or launch continuous practice mode.
4. **Track Growth:** Review your statistics table to focus on weaker phrases.
